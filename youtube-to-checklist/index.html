From a YouTube link to your first checklist

Start with a tutorial that explains a clear sequence of actions.

Step 01

Copy and paste the link

Copy the video's link from YouTube. In SaySo's list import screen, choose YouTube, then tap Paste YouTube Link.

Step 02

Analyze and review

Tap Analyze Video. When the preview is ready, check each step against the tutorial, edit the wording, and remove anything you do not need.

Step 03

Save and follow

Name your list and tap Make it Sticky to save it. Work through the checklist and return to the source whenever a technique needs a closer look.

Import requires an internet connection. Processing time and results depend on the source; a generated list can be incomplete or wrong. Review measurements, sequence, and safety details before starting.

What should the finished list look like?

A useful checklist describes actions, not a summary of what the creator talked about.

Example: a paper-folding tutorial

  1. Gather a square sheet of paper and clear a flat surface.
  2. Make the first fold shown in the tutorial.
  3. Match the corners and crease the fold.
  4. Replay the next fold, checking which side faces up.
  5. Compare the finished shape with the creator's example.

This is an illustrative outline, not output from a tested import. The video's exact folds belong in your reviewed list. Keep visual details in the original tutorial instead of guessing from a short step.

Before you save

  • Gathering materials comes before using them.
  • Each step starts with an action.
  • Measurements match the original source.
  • Missing visual details send you back to the video.

When an import needs a different approach

Not every YouTube link can become a reliable checklist.

The link fails or the steps are incomplete

Check your connection and that the video is accessible. Retry the import if it failed. If the tutorial relies on silent visual demonstrations or leaves out key instructions, write the missing steps yourself using the manual checklist guide. Do not treat a generated list as a full record of the video.

The tutorial has a written companion

A recipe page or written how-to may give you a clearer starting point for ingredients, quantities, and ordered instructions. See how to import a webpage as a checklist.
